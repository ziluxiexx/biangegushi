# 编个故事

[English](README_EN.md)

一个把随手填词变成意外故事的轻量小游戏，面向手机端和小红书小工具容器设计。

**开发说明：** 本项目使用 Codex 构建并持续迭代，多个历史版本曾通过小红书小工具平台进行开发、测试与发布。当前 GitHub 仓库是在多轮迭代后整理建立的，因此仓库中的提交数量并不代表项目实际经历的完整开发与版本迭代次数。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

故事内容与界面代码分离，最终运行使用 `src/data/finalStories.js` 中的本地故事库，不依赖后端或实时 AI 生成。
